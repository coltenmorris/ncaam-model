NCAAM MODEL ON GITHUB: FRESH START

A. Clean repo (easiest way to remove everything)
   1. Repo > Settings > scroll to the bottom (Danger Zone) > Delete this repository.
   2. github.com > + (top right) > New repository. Name: ncaam-model. Public.
      Leave every box unchecked. Create repository.

B. Upload the files
   1. On the empty repo page, click "uploading an existing file".
   2. Open this ncaam-model folder, press Ctrl+A, drag everything onto the page.
   3. Wait until all 18 files are listed, then click Commit changes.
   4. Check the repo shows espn.py, model.py, web.py, main.py etc.

C. Create the schedule file (must be typed, folders can't be uploaded)
   1. Add file > Create new file.
   2. Name box, type exactly:  .github/workflows/daily.yml
   3. Open daily.yml from this folder in Notepad, copy all, paste, Commit changes.

D. Odds API key (a new repo needs it added again)
   Settings > Secrets and variables > Actions > New repository secret
   Name: ODDS_API_KEY     Secret: your key     > Add secret

E. Web page
   Settings > Pages > Build and deployment > Source: GitHub Actions

F. First run
   Actions tab > (enable workflows if asked) > Daily NCAAM update > Run workflow.
   Green check after ~2 minutes. Page: https://coltenmorris.github.io/ncaam-model/

After that it runs by itself at about 10 AM and 5 PM Eastern every day.
