Sportsbook edge picks

Dashed line = 52.4%, break-even against the spread at -110.

How to read this

Units

A unit is one standard bet. Units = profit or loss if you bet 1 unit on every pick in a group. Against the spread at the usual -110 price, a win pays +0.91, a loss costs -1, and a push is 0. So +5.00 units means you would be up five bets' worth; with $100 bets that is +$500. Because a loss costs more than a win pays, you need to win 52.4% just to break even. Market picks are paid at the market's own price instead of -110.

Closing line value

Edge picks

The line usually moves toward the right number before tip-off, as sharp money comes in. If the line you could have bet when the pick first appeared is better than the closing line (the last line before tip-off), the pick beat the close. Beating the close more than half the time is one of the strongest signs a model finds real value, and it shows up after far fewer games than win-loss does. Opening = first run that saw the game; closing = last run before tip-off.
